# DOCUMENTATION

## This directory is to record documentation of functions

### FORMATTING

Documents are to be made under this format;

- Header

  - Use H1s to specify file name.

  - Use H2s to specify file purpose.

- Seperation

  - Use horizonal line breaks to seperate sections.

- Executable
  
  - Use H2s for argv documentation.

  - Use function syntax for how to interface with sockets.

- Functions

  - Use H2s for function name.

  - Use blockquotes for function description.

  - Use bold for function return value.

  - Use italics for function arguments.

  - Use tables for functon speed details.

  - If needed, use in depth explanation of the function in backticks and the language of your choice.

  - Avoid strikethroughs, or footnotes.

  - If in progress, make a task list of what to do.

  - Advanced styling is highly reconmended.

- Conclusion

  - If in progress, make a task list of what to do.

  - List important function names

### NOTES

1. Use $...$ for inline math, and $$...$$ for math that spans multiple lines.

- To use special symbols, like the blackboard U, you may have to use unicode, or LaTeX syntax.

2. Use github syntax.
