# Documentation for the "main_api.c" file in the directory "api"

## The main_api.c file is the source code for the main api of Volun. This is essential to operating the app, and must be started to start the app

---

## ARGV

---

## argv[1]

> Port number to host a server socket on, must be unsigned short int, or else program will exit with a status of 1. Must be present, or else program will exit with status of 1.

---

## argv[2]

> IP to connect to, an IP, or else program will exit with a status of 2. Must be present, or else program will exit with status of 2.

---

## argv[3]

> Port number for server socket, must be unsigned short int, or else program will exit with a status of 3. Must be present, or else program will exit with status of 3.
